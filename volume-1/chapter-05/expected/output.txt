centred 8x8                      64     0.967         64     0.978
shifted on 12x12 canvas         144     0.309        144     0.707
------------------------------------------------------------------

Centred digits: the two are within noise of each other.
  The digits never move, so a pixel index is already a reliable feature.
  Convolution has little to add when position is fixed.

Shifted digits: convolutional features lead by +0.398.
  Raw pixels fall by 0.658; convolutional features fall by 0.271.

That difference is what convolution buys. The same kernel is applied at
every position and pooling discards exactly where it fired, so the
features barely change when the digit moves. A raw-pixel classifier has
to learn every position separately and mostly fails. Real images are
never perfectly centred, which is why CNNs displaced pixel classifiers.
